# 1. مفتاح Anthropic API

**الوقت المتوقع:** 15 دقيقة
**بيفتح:** أول نداء حقيقي للموديل، وأول قياس للتكلفة ومعدل إصابة الكاش.

## الخطوات

1. **افتح** `platform.claude.com` واعمل حساب (أو ادخل بحسابك).

2. **اعمل Organization** باسم الشركة لو مطلوب منك.

3. **حط رصيد** — النظام **prepaid**، يعني بتشحن رصيد ويتخصم منه.
   - ابدأ بـ **$20–30**. كفاية أكتر من 200 محادثة اختبار.
   - مش لازم تحط أكتر دلوقتي — بنقيس الأول وبعدين نقرر.

4. **مهم: اعمل Workspace منفصل** اسمه `receptionist`.
   - Settings → Workspaces → Create
   - **ليه:** بيعزل إنفاق موظف الاستقبال عن أي استخدام تاني، وبيخليك تشوف تكلفته الحقيقية في لوحة الاستخدام بدل ما تتلخبط مع campaign-os. وكمان تقدر تحط سقف إنفاق للـ workspace لوحده.

5. **حط سقف إنفاق** (Limits / Budget) على الـ workspace ده.
   - اقتراح: **$50/شهر** في البداية. لو اتخطى، الطلبات بتقف بدل ما الفاتورة تكبر من غير ما تحس.

6. **اعمل المفتاح**: API Keys → Create Key → اختار الـ workspace بتاع `receptionist`.
   - الشكل: `sk-ant-api03-...`
   - **بيتعرض مرة واحدة بس.** انسخه فوراً.

## ⚠️ فين تحطه — مهم جداً

**متحطهوش في المشروع خالص.** `.env.production` لسه متتبع في git على repo عام من 29 يوليو، وأي مفتاح يقرب من المشروع دلوقتي بيتسرب.

**الطريقة الصح:** متغير بيئة على السيرفر نفسه:
```
ANTHROPIC_API_KEY=sk-ant-api03-...
```

**البديل (لما السيرفر يبقى جاهز):** من لوحة التحكم → الذكاء الاصطناعي → Providers → أضف provider اسمه `anthropic`. بيتخزن في قاعدة البيانات وبيتعرض مقنّع. الكود بيدور على الاتنين.

## اللي تبعتهولي

مش محتاج تبعتلي المفتاح نفسه. ابعتلي بس: **"المفتاح جاهز وموجود على السيرفر"** — وقولي حطيته كمتغير بيئة ولا في لوحة التحكم.

# 2. Meta — التوثيق والتطبيق

**الوقت المتوقع:** ساعة شغل + **1 إلى 3 أسابيع انتظار**
**بيفتح:** التلات صفحات.
**⚠️ ده المسار الحرج الوحيد اللي مش تحت سيطرتنا. ابدأ فيه النهاردة.**

## الجزء أ — Business Portfolio والتوثيق (الطويل)

1. **افتح** `business.facebook.com`.

2. **اتأكد إن عندك Business Portfolio** فيه الشركة. لو مفيش، اعمل واحد باسم الكيان القانوني الحقيقي — **الاسم لازم يطابق السجل التجاري بالحرف**.

3. **ضيف الصفحات التلاتة** للـ Portfolio: INSAN · Future · Delta.
   - Business Settings → Accounts → Pages → Add

4. **ابدأ التوثيق**: Business Settings → **Security Center** → Business Verification → Start Verification

5. **المستندات (مصر) — والقايمة دي "أو" مش "و"**

   Meta عايزة مستند يثبت الاسم القانوني والعنوان. القايمة **خيارات بديلة**،
   مش طبقات فوق بعض:

   | المستند | مقبول؟ |
   |---|---|
   | **السجل التجاري** | ✅ وبيتضمن العنوان أصلاً |
   | **البطاقة الضريبية** | ✅ |
   | **عقد التأسيس** | ✅ |
   | كشف حساب بنكي | بديل — لكيان مالوش سجل تجاري |
   | فاتورة مرافق | بديل |
   | رخصة مزاولة نشاط | بديل |

   > **الحساب البنكي مش جزء من التوثيق أصلاً.** التوثيق بيثبت إن الكيان
   > القانوني موجود. وسيلة الدفع حاجة تانية خالص، بتتحقق لوحدها وقت إعداد
   > حساب الإعلانات. اسم بنكي مختلف **مايعطّلش المراسلة**.

   **📌 الوضع الحالي (2026-08-03):** ويدج جروب عندها السجل التجاري والبطاقة
   الضريبية وعقد التأسيس — **التلاتة على القايمة**. ده كفاية للتقديم.

   **اللي بيرفض الطلبات فعلاً مش نقص المستندات — عدم تطابق الاسم:**
   - الاسم في Meta **مطابق حرفياً** لللي في السجل التجاري. لو السجل بيقول
     "شركة ويدج جروب للخدمات الطبية"، تكتبه كده بالظبط — مش "Wedge Group".
   - العنوان مطابق لللي في السجل
   - صورة **كاملة وواضحة**؛ المقصوصة أو الباهتة بترفض
   - رقم تليفون الشركة شغال — بيتصلوا أو بيبعتوا كود، ولازم حد يرد

   **قدّم بالموجود.** التقديم مجاني وقابل للإعادة، والرفض بيقولك بالظبط إيه
   الناقص — وده معلومة أنفع من أي تخمين. لو طلبوا إثبات عنوان إضافي، البدائل
   باسم الشركة: عقد الإيجار · مراسلة حكومية رسمية · شهادة التأمينات الاجتماعية.

   **⚠️ كيان واحد بيكفي للتلات صفحات.** التوثيق بيتم على الـ Business Portfolio
   مش على كل صفحة، والصفحات **مش لازم** تكون مملوكة للكيان اللي وثّق. يعني
   مستندات لافينير وإنسان مش مطلوبة — وثّق بويدج جروب وضيف التلاتة تحته.

6. **قدّم واستنى.** غالباً 2–5 أيام عمل، وممكن يوصل لـ 3 أسابيع لو طلبوا مستندات إضافية.

## الجزء ب — التطبيق (تقدر تعمله وإنت مستني التوثيق)

7. **افتح** `developers.facebook.com` → My Apps → Create App
   - النوع: **Business**
   - اربطه بالـ Business Portfolio بتاعك

8. **ضيف منتج Messenger** للتطبيق.

9. **من Settings → Basic خد:**
   - **App ID**
   - **App Secret** (اضغط Show)

10. **من Messenger → Settings:**
    - اربط الصفحات التلاتة
    - **ولّد Page Access Token لكل صفحة** (3 توكنات)
    - سجّل **Page ID لكل صفحة** (بتلاقيه في About بتاع الصفحة أو في نفس الشاشة)

11. **اختار Verify Token** — دي كلمة سر بتختارها إنت، أي حاجة عشوائية طويلة. اكتبها عندك.

## الجزء ج — الـ Webhook (لما السيرفر يبقى جاهز)

12. Messenger → Settings → Webhooks → Add Callback URL
    - **Callback URL:** `https://<دومينك>/api/v1/receptionist/messenger/webhook`
    - **Verify Token:** اللي اخترته في خطوة 11
    - **Subscribe to:** `messages` و `messaging_postbacks`

13. **اربط الصفحات التلاتة بالـ webhook** (Subscribe لكل واحدة).

## 🎁 حاجة مهمة تخليك تختبر من غير ما تستنى

**التطبيق وهو في Development mode بيقدر يبعت ويستقبل رسائل من أي حد ليه دور فيه** — Admin أو Developer أو Tester.

يعني:
- ضيف نفسك (وأي حد هيجرب) كـ **Tester** من App Roles
- كلّم الصفحة من حسابك الشخصي
- **هيشتغل بالكامل** — من غير App Review ومن غير Business Verification

**النتيجة:** نقدر نختبر ماسنجر من الطرف للطرف وإحنا مستنيين الموافقة. الموافقة محتاجة عشان **الجمهور العام** يقدر يكلم الصفحة، مش عشان السيستم يشتغل.

## الجزء د — App Review (آخر خطوة قبل الجمهور)

14. بعد ما التوثيق يخلص، قدّم App Review على صلاحية **`pages_messaging`**.
    - محتاج: وصف حالة الاستخدام، **فيديو تسجيل شاشة** بيوضح السيناريو، وحساب اختبار
    - أنا هساعدك في نص الوصف والسيناريو لما نوصل هناك

## اللي تبعتهولي

لما تخلص الجزء ب، ابعتلي:

```
FB_APP_ID          = ...
FB_APP_SECRET      = ...   (ده سر — ابعته بطريقة آمنة مش في شات عام)
FB_VERIFY_TOKEN    = ...   (اللي إنت اخترته)

INSAN  → Page ID: ...  Token: ...
FUTURE → Page ID: ...  Token: ...
DELTA  → Page ID: ...  Token: ...
```

الـ Page IDs مش أسرار — دي بتتحط في قاعدة البيانات مكان `placeholder` الموجود دلوقتي. الـ Secret والتوكنات أسرار.
