# أمر شغل — نشر محرّر القوائم الجديد في لوحة التحكم

**الكوميتات المطلوب نشرها:** `5b35d94` و `bfda130` (الاتنين موجودين على `main`)

**اقرأ المهام بالترتيب. لا تبدأ مهمة قبل ما تخلّص اللي قبلها وتلصق مخرجاتها.**

---

## خلفية — إيه اللي اتغيّر ولماذا

في لوحة التحكم، صفحة المستشفيات ← تبويب «الأقسام»، كانت حقول **الأجهزة** و**الخدمات**
و**المميزات** عبارة عن ثلاث خانات نص بتطلب من المستخدم يكتب مصفوفة JSON بإيده:

```
[{"ar":"خدمة","en":"service"}]
```

ده مستحيل على أي حد غير تقني. والأسوأ إن الكود كان بيعمل `JSON.parse` جوّه
`try { } catch(e){}` فاضي — يعني لو المستخدم كتب JSON غلط، **مفيش رسالة خطأ**،
النص الخام كان بيتبعت للـ API واللي يرجّع خطأ غامض.

الحقول دي اتحوّلت لمحرّر صفوف: كل عنصر سطر فيه خانة عربي وخانة إنجليزي، مع
أزرار إضافة وحذف وترتيب، وخانة «لصق مجمّع» لإدخال عدة عناصر مرة واحدة.

**شكل البيانات المخزَّنة لم يتغيّر** — لسه مصفوفة من `{ ar, en }`. يعني الـ API
وصفحات الموقع العامة مش محتاجة أي تعديل.

## المهمة 1 — النشر

سكربت النشر اتصلح (كان بيروح على `/app` و `/root/website` وهما مش موجودين).
**استخدم السكربت اللي في الريبو، متكتبش سكربت مخصص:**

```bash
pwsh website/deploy-to-contabo.ps1
```

لو مش شغّال عندك PowerShell، نفّذ نفس الخطوات يدوياً على السيرفر:

```bash
cd /root/INSAN-Healthcare-Platform && git checkout main && git pull origin main && git rev-parse --short HEAD && docker compose down && docker compose up -d --build
```

**⚠️ مهم:** الـ build المحلي عندي بيفشل بسبب مشكلة نظام ملفات في جوجل درايف
(`EINVAL: invalid argument, write`) — مش مشكلة كود. الـ TypeScript عدّى نظيف
(`tsc --noEmit` = 0 أخطاء). **فالتحقق الحقيقي من الـ build هو بتاعك داخل Docker.**

**الصق مخرجات هذا الأمر:**

```bash
cd /root/INSAN-Healthcare-Platform && git rev-parse --short HEAD && docker compose ps
```

**شرط النجاح:** الـ commit يساوي `bfda130` وكل الحاويات حالتها `running` أو `healthy`.

**لو الـ build فشل:** الصق آخر 40 سطر من مخرجات الـ build كما هي. **ما تحاولش
تصلح بنفسك وما ترجّعش الكوميت.**

## المهمة 2 — اختبار الذهاب والعودة (أهم خطوة — لا تتخطاها)

الخطر الوحيد في التغيير ده إن قراءة البيانات القديمة أو كتابتها تبوّظ محتوى موجود.
لازم نتأكد على **قسم واحد بس** قبل ما نلمس أي حاجة تانية.

1. افتح لوحة التحكم ← المستشفيات ← عدّل **مستشفى الدلتا** ← تبويب **الأقسام**.
2. دوّر على القسم اللي `slug` بتاعه `emergency-department`.
3. **بصّ بعينك** على حقول «مميزات القسم» و«الخدمات الطبية».

   **شرط النجاح:** تشوف صفوف مليانة نص عربي — 5 مميزات و7 خدمات، كل صف فيه
   خانة عربي وخانة إنجليزي منفصلين. أول ميزة المفروض تكون
   «عمل متواصل 24 ساعة طوال أيام الأسبوع» وأول خدمة «الفرز الفوري والإنعاش».

   **لو الصفوف طلعت فاضية أو مش ظاهرة أصلاً — قف فوراً، ما تحفظش، وبلّغ.**

4. **من غير ما تغيّر أي حاجة**، اضغط «حفظ التعديلات».
5. استنى دقيقة، وبعدين افتح الصفحة دي في المتصفح:

   `http://169.58.77.61/hospitals/delta-hospital/departments/emergency-department`

**الصق مخرجات هذا الأمر** (نفّذه في Console المتصفح وإنت على الصفحة):

```javascript
JSON.stringify([...document.querySelectorAll('h2,h3')]
  .filter(h => /مميزات القسم|الخدمات الطبية/.test(h.textContent))
  .map(h => {
    const items = [...(h.parentElement.querySelectorAll('li') || [])].map(li => li.textContent.trim());
    return { heading: h.textContent.trim(), count: items.length, first: items[0], empty: items.filter(t => !t).length };
  }), null, 2)
```

**شرط النجاح — الثلاثة مع بعض:**
- `count` = 5 للمميزات و 7 للخدمات
- `empty` = **0** في الاتنين
- `first` فيه نص عربي حقيقي مش فاضي

**لو أي شرط فشل:** بلّغ فوراً والصق الناتج كما هو. **ما تحفظش أي قسم تاني.**

## المهمة 3 — اختبار الإدخال الجديد

بعد ما المهمة 2 تنجح فقط.

1. نفس الشاشة، قسم `emergency-department`.
2. في «مميزات القسم» اضغط **«إضافة ميزة»** — المفروض يظهر صف فاضي جديد.
3. اكتب في خانة العربي: `اختبار مؤقت` — وسيب الإنجليزي فاضي.
4. احفظ، استنى دقيقة، وافتح صفحة القسم وتأكد إن «اختبار مؤقت» ظهرت في آخر القائمة.
5. **ارجع للوحة التحكم واحذف الصف ده بزرار سلة المهملات، واحفظ تاني.**
6. تأكد إن الصفحة رجعت 5 مميزات زي الأول.

**الصق:** لقطة شاشة لحقل «مميزات القسم» وهو مليان صفوف، + تأكيد إن العدد رجع 5.

## المهمة 4 — اختبار اللصق المجمّع

بعد ما المهمة 3 تنجح فقط.

1. نفس الشاشة، اضغط **«لصق مجمّع»** جنب «مميزات القسم».
2. المفروض تفتح خانة نص فيها شرح.
3. **ما تلصقش حاجة وما تضغطش «استبدال القائمة بالمُلصَق»** — اضغط «إلغاء» بس.

الغرض من الاختبار ده إن الزرار يفتح ويقفل من غير ما يمسح حاجة.

**⚠️ تحذير مهم:** زرار «استبدال القائمة بالمُلصَق» **بيمسح كل العناصر الحالية**
ويحطّ مكانها اللي إنت لصقته. استخدمه بس لما تكون عايز تملأ قسم فاضي من الصفر.

**الصق:** تأكيد إن الخانة فتحت وقفلت والقائمة فضلت 5 عناصر زي ما هي.
