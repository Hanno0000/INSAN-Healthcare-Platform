## 3. نظام المسافات (Spacing Scale)

قاعدة 4px: `4, 8, 12, 16, 24, 32, 48, 64, 96` px — تُستخدم كمتغيرات CSS (`--space-1` إلى `--space-9`) بدل أرقام حرة، لضمان اتساق كل الفراغات بين العناصر عبر المنصة بالكامل.

## 8. النماذج (Forms)

- Input height: 44px (يضمن سهولة اللمس على الموبايل)
- Border: 1px Neutral Gray 300، يتحول لـ Accent Blue عند Focus
- رسائل الخطأ تظهر أسفل الحقل مباشرة بلون Error، مع أيقونة تحذير صغيرة
- كل حقل إجباري يُعلَّم بنجمة `*` بجانب الـ Label
- **ملاحظة:** التحقق من صحة المدخلات في الواجهة يتم بـ React Hook Form + Zod schemas، بينما class-validator يتحقق على الـ API (انظر [01 — System Architecture](../architecture/01_ARCHITECTURE.md)).

### توقيت التحقق (Validation Timing)

| الحالة | متى يتحقق | السلوك |
|---|---|---|
| ** touched + changed** | عند مغادرة الحقل (`onBlur`) | يعرض الخطأ أسفل الحقل فوراً |
| **إرسال النموذج** | عند الضغط على زر الإرسال | يعرض كل الأخطاء دفعة واحدة + يركز أول حقل به خطأ |
| **أثناء الكتابة** | لا يتحقق أثناء الكتابة | يُوقف الأخطاء المعروضة حتى يغادر المستخدم الحقل (يمنع "الصراخ" الأحمر أثناء الكتابة) |

**الحالة الاستثنائية:** حقل `email` يتحقق من الصيغة أثناء الكتابة بعد أول `onBlur` (لأن المستخدم يكتب ببطء وقد ينسى التنسيق).

### منع الإرسال المزدوج (Double-Submit Prevention)

```
1. عند الضغط على زر الإرسال:
   → الزر يتحول لـ Loading state (Spinner داخلي + نص "جاري الإرسال...")
   → الزر يصبح disabled
   → يتم تعطيل جميع أزرار النموذج

2. بعد النجاح:
   → الزر يعود لحالته الطبيعية

3. بعد الخطأ:
   → الزر يعود لحالته الطبيعية
   → المستخدم يُشجَّع على إعادة المحاولة (لا يُعاد تحميل الصفحة)
```

**لا يُسمح بـ:** Debounce على زر الإرسال كبديل — الزر يجب أن يصبح `disabled` فوراً.

### تحذير التغييرات غير المحفوظة (Unsaved Changes Warning)

| الحالة | السلوك |
|---|---|
| **النموذج فارغ أو لم يُعدَّل** | لا شيء — التنقل حر |
| **النموذج يحتوي على تغييرات غير محفوظة** | `beforeunload` event + confirmation dialog مخصص: "لديك تغييرات غير محفوظة. مغادرة الصفحة ستحذفها." |
| **النموذج جزئياً محفوظ (Draft)** | نفس السلوك أعلاه |
| **الحالة المحفوظة** | لا تحذير (التغييرات محفوظة فعلاً) |

**التنفيذ:**
- `beforeunload` للتنقل بين الصفحات (native browser dialog)
- Dialog مخصص (`ConfirmDialog` component) للتنقل داخل SPA (React Router)
- تتبع التغييرات عبر `dirtyFields` من React Hook Form

### إشعارات النجاح (Success Notifications)

| نوع العملية | الإشعار | المدة |
|---|---|---|
| **حفظ / تعديل** | Toast في الزاوية العلوية اليمنى: "تم الحفظ بنجاح" | 3 ثوانٍ تلقائياً |
| **نشر (Publish)** | Toast: "تم النشر — الصفحة الآن مباشرة" مع رابط "عرض الصفحة" | 5 ثوانٍ |
| **حذف** | Toast: "تم الحذف" مع زر "تراجع" (Undo) لمدة 10 ثوانٍ | 10 ثوانٍ |
| **إرسال نموذج عام** | رسالة نجاح داخل الصفحة (بديل Toast) مع أيقونة نجاح | يُزال يدوياً عند التنقل |

### عرض الأخطاء (Error Presentation)

| مصدر الخطأ | العرض | المثال |
|---|---|---|
| **خطأ حقل واحد** | رسالة خطأ أسفل الحقل + حدود حمراء + أيقونة | "البريد الإلكتروني غير صحيح" |
| **عدة أخطاء حقول** | كل الحقول الخاطئة تُعلَّم + رسالة عامة أعلى النموذج: "يرجى تصحيح الأخطاء التالية" | — |
| **خطأ server (400)** | رسالة عامة أعلى النموذج + تمييز الحقول المحددة إن أمكن | "البريد مسجل مسبقاً" |
| **خطأ server (401/403)** | تحويل لصفحة Login مع رسالة | "انتهت صلاحية الجلسة" |
| **خطأ server (429)** | رسالة مع `Retry-After`: "تم تجاوز الحد — يرجى المحاولة بعد X ثوانٍ" | — |
| **خطأ server (500)** | رسالة عامة: "حدث خطأ غير متوقع — يرجى المحاولة لاحقاً" + `requestId` للمتابعة | — |
| **خطأ شبكة (offline)** | Toast: "لا يوجد اتصال بالإنترنت" + إعادة محاولة تلقائية عند عودة الاتصال | — |

## 10. الحركة (Motion)

### المبدأ العام

حركة هادئة وواثقة، ليست صاخبة أو مبالغ فيها — تعكس شخصية البراند: Calm, Confident, Human.

### مدة الأنيميشن (Duration)

| النوع | المدة | الاستخدام |
|---|---|---|
| **Micro** | 100–150ms | Hover states, Focus ring, Toggle switches |
| **Small** | 200–250ms | Fade in/out, Tooltip, Dropdown open, Tab switch |
| **Medium** | 300–350ms | Modal enter/exit, Drawer slide, Card expand |
| **Large** | 400–500ms | Page transition, Hero content reveal, Full-page skeleton fade |

### Easing

| الاتجاه | الدالة | CSS |
|---|---|---|
| **الدخول** (Enter) | Decelerate | `cubic-bezier(0.0, 0.0, 0.2, 1)` |
| **الخروج** (Exit) | Accelerate | `cubic-bezier(0.4, 0.0, 1, 1)` |
| **التحوّل** (Transition) | Standard | `cubic-bezier(0.4, 0.0, 0.2, 1)` |

### قواعد الحركة

| القاعدة | التفاصيل |
|---|---|
| **لا Bounce** | ممنوع: elastic, bounce, spring animations — تبدو غير احترافية |
| **لا Auto-play Video** | فيديو بدون صوت فقط، ويتطلب `prefers-reduced-motion` check |
| **لا Parallax مبالغ** | تأثير بسيط (≤20px shift) على Hero فقط — لا يُستخدم في باقي الصفحة |
| **Consistent Direction** | العناصر تظهر من الأسفل للأعلى (Fade Up) في RTL و LTR — لا تظهر من اليمين/اليسار |
| **Stagger** | عند عرض عدة بطاقات: stagger 50–75ms لكل بطاقة (الأولى تظهر أولاً) |

### Reduced Motion (`prefers-reduced-motion`)

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

**السلوك:**
- كل الأنيميشنات تتحول لـ `instant` (0ms)
- Scroll-based animations (IntersectionObserver) تُ.fillRect فوراً بدون انتظار
- Skeleton shimmer يتوقف (يُعرض كثابت بدون حركة)
- Page transitions تتخطى وtransitions تظهر المحتوى فوراً
- **لا يُزال** focus ring visible (الوصولية لا تتوقف)

## 11. قواعد الوصولية (Accessibility)

- تباين الألوان ≥ 4.5:1 لكل نص أساسي (تم اختيار الباليت أعلاه بما يحقق هذا مع الأبيض والنيفي).
- كل عنصر تفاعلي قابل للوصول بلوحة المفاتيح (Tab) بترتيب منطقي.
- `focus-visible` بحدود واضحة (2px Accent Blue) على كل العناصر القابلة للتفاعل.
- دعم RTL كامل عبر خصائص CSS منطقية (`inset-inline`, `margin-inline`) بدل `left/right` المباشرة.
- الصور دائماً بـ `alt text` (يُدار من الأدمن كحقل `{ar,en}` إجباري).

## 13. الحالات الفارغة (Empty States)

### المبدأ

كل شاشة تحتوي على قائمة أو شبكة يجب أن تحتوي على حالة فارغة واضحة ومفيدة — لا تُعرض أبداً شاشة بيضاء بدون تفسير.

### هيكل Empty State الموحّد

```
┌─────────────────────────────────┐
│          [Icon: 48px]           │
│                                 │
│       Title (H3, Gray 700)     │
│                                 │
│   Description (Body, Gray 500) │
│                                 │
│     [Primary Action Button]     │
│      (optional, contextual)     │
│                                 │
└─────────────────────────────────┘
```

| الخاصية | القيمة |
|---|---|
| **الأيقونة** | Lucide icon بحجم 48px بلون Gray 300 |
| **العنوان** | H3، Gray 700، نص واضح ومختصر (3-5 كلمات) |
| **الوصف** | Body، Gray 500، جملة واحدة توضح لماذا الشاشة فارغة |
| **الزر** | اختياري — يظهر فقط إذا كان هناك إجراء محدد يمكن للمستخدم اتخاذه |

### مكتبة الحالات الفارغة

| الحالة | العنوان | الوصف | الزر | الأيقونة |
|---|---|---|---|---|
| **لا توجد بيانات** | لا يوجد محتوى بعد | "لم يُضَف أي محتوى إلى هذا القسم بعد." | لا | `Inbox` |
| **لا توجد نتائج بحث** | لا توجد نتائج | "جرّب كلمات بحث مختلفة أو تصفّر الفلاتر." | لا (أو "مسح الفلاتر") | `SearchX` |
| **لا توجد أخبار** | لا توجد أخبار بعد | "ستظهر الأخبار هنا بمجرد نشرها أو مزامنتها من السوشيال ميديا." | لا | `Newspaper` |
| **لا توجد مستشفيات** | لا توجد مستشفيات | "ستظهر المستشفيات هنا بمجرد إضافتها من لوحة التحكم." | لا | `Hospital` |
| **لا توجد أطباء** | لا توجد أطباء | "سيظهر الأطباء هنا بمجرد ربطهم بالمستشفيات والمراكز." | لا | `Stethoscope` |
| **لا توجد وسائط** | مكتبة الوسائط فارغة | "ارفع صوراً أو فيديوهات لتبدأ في بناء مكتبة الوسائط." | "رفع ملف" | `Upload` |
| **لا توجد محادثات AI** | لا توجد محادثات بعد | "ستظهر محادثات الزوار هنا عند بدء أول محادثة." | لا | `MessageSquare` |
| **لا توجد حجوزات** | لا توجد طلبات حجز | "ستظهر طلبات الحجوزات هنا عند تقديم أول طلب." | لا | `CalendarX` |
| **لا توجد رسائل تواصل** | لا توجد رسائل | "ستظهر رسائل التواصل هنا عند استلام أول رسالة." | لا | `Mail` |
| **الفلاتر لا تطيّب نتائج** | لا توجد نتائج مطابقة | "جرّب تعديل الفلاتر لعرض نتائج أكثر." | "مسح الفلاتر" | `FilterX` |

### قواعد العرض

| القاعدة | التفاصيل |
|---|---|
| **أولوية الأيقونة** | تظهر دائمًا — لا تُستبعَد في Mobile |
| **الزر** | يظهر فقط إذا كان هناك action محدد (رفع ملف، مسح فلاتر، إنشاء عنصر) |
| **الترجمة** | كل نص بالـ `{ar, en}` — يُدار من المحتوى الإداري أو يُعرَّف كـ constant |
| **الحد الأدنى من المساحة** | Padding: 64px top/bottom (Desktop) · 48px (Mobile) — لا تُقصَر الحالات الفارغة |

## 14. حالات التحميل (Loading States)

### المبدأ

المستخدم يجب أن يعرف دائمًا ما إذا كان النظام يعمل أو توقف. لا تُعرض أبداً شاشة بيضاء بدون مؤشر.

### Skeleton Screens (المطلوبة)

تُستخدم في كل شاشة تعرض محتوى من السيرفر — تُقدّم معاينة بصرية للشكل النهائي:

| الموقع | نوع Skeleton | الملاحظات |
|---|---|---|
| **صفحة (Home, Hospital Detail, News)** | Skeleton يطابق تخطيط الصفحة بالضبط (Hero skeleton + Cards skeleton) | يظهر لمدة ≥300ms ثم يتحول للمحتوى |
| **جداول الأدمن** | Skeleton rows (5-8 صف) مع header skeleton | يظهر فوراً عند تغيير الصفحة/الفلتر |
| **بطاقات (Cards Grid)** | Skeleton cards بنفس أبعاد البطاقات الحقيقية | يظهر عند تحميل القائمة |
| **تفاصيل كيان** | Skeleton لجميع الحقول + الصور | — |
| **الشات بوت** | Skeleton messages (3-4 bubbles) | عند فتح المحادثة |

**خصائص Skeleton:**
- **اللون:** Gray 100 (خلفية) + Gray 200 (shimmer) — لا أبيض نقي
- **الحركة:** Shimmer effect بحركة أفقية واحدة (left → right) — `@keyframes shimmer`
- **المدة:** 1.5 ثانية لكل cycle، loop直到 تحميل البيانات
- **الشكل:** يطابق شكل المحتوى النهائي (circles للصور، rectangles للنصوص، بأحجام متغيرة)
- **الاستثناء:** لا shimmer مع `prefers-reduced-motion` — يُعرض كثابت

### Spinners (المقبولة فقط في الحالات التالية)

| الموقع | نوع Spinner | الملاحظات |
|---|---|---|
| **داخل زر** | Spinner صغير (16px) بدل النص | عند إرسال نموذج / تنفيذ إجراء |
| **صفحة كاملة (نادرة)** | Spinner مركزي + نص "جاري التحميل..." | فقط إذا لا يوجد Skeleton مناسب (مثل صفحة Login) |
| **تحميل المزيد (Infinite Scroll)** | Spinner صغير أسفل القائمة | — |
| **رفع ملف** | Progress bar بدل Spinner | يعرض النسبة المئوية الفعلية |

**لا يُسمح بـ:** Spinner في وسط شاشة بها محتوى جزئي — استخدم Skeleton بدلها.

### جدول القرار

| السيناريو | Skeleton أم Spinner؟ |
|---|---|
| تحميل الصفحة بالكامل | **Skeleton** |
| تحميل قائمة/جدول | **Skeleton** |
| إرسال نموذج | **Spinner** (داخل الزر) |
| حذف عنصر | **Spinner** (داخل الزر) |
| نشر محتوى | **Spinner** (داخل الزر) |
| تحميل محادثة شات | **Skeleton** |
| رفع ملف | **Progress Bar** |
| لا يوجد محتوى مناسب لـ Skeleton | **Spinner** مع نص |
