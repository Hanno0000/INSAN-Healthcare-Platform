## Tech Stack

- **Frontend:** Next.js 14+ (App Router)
- **Backend:** NestJS
- **Database:** PostgreSQL + Prisma
- **Deployment:** Docker
- **i18n:** Arabic (default) + English

- `assets/logo/` - Brand logos (Arabic, English, Symbol, Horizontal)
- `data/` - Reference documents (hospital descriptions, etc.)
